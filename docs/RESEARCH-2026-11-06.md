## Shipped: `ledger confirm`

Provenance already decided gate force (agent/summary entries are advisory unless a falsifier trips), but
there was no way to promote an agent entry the user endorsed. `Store.confirm(id, by="user")` sets
`confirmed_by_user`; `Entry.user_authority` (source=user or confirmed) now drives hard-deny, the
authority rule for supersede/retire, and the turn check. The agent cannot confirm (refusal is logged as
`confirm_refused`), and there is no automatic or N-observation promotion, since an agent corroborating
itself is the self-confidence loop DESIGN §8 rejects.

## Specified next: shadow-mode `possibly_invalidated`

One extra output field in the existing extractor call (`possibly_invalidated:[{id, evidence}]`), with
verbatim evidence checked by `evidence_supported`. It never changes status (an `unknown_current` flip
disables enforcement, and STALE's best model is ~55% accurate). It only appends a review-candidate
intervention, never demotes `source=user` entries, and stays off until a labeled set shows ~90% precision.
