==============================================================================
  SECTION 7: LIMITATIONS AND CAVEATS
==============================================================================

  1. EMBEDDING MODEL: Uses deterministic hash-based embeddings, not a
     learned model. Recall rates with a real embedding model (e.g.,
     sentence-transformers) would likely differ. The hash embedder has
     no semantic understanding -- it can only match on lexical overlap
     via the keyword component of hybrid search.

  2. DECISION DISTRIBUTION: Decisions are uniformly distributed across
     the conversation window. Real conversations may cluster decisions
     around specific topics or time periods.

  3. BASELINE SIMPLICITY: The no-memory baseline uses a fixed lossy
     summary. Real context compaction (e.g., Claude Code's) may retain
     more or less information depending on the compaction algorithm.

  4. SINGLE-MACHINE TIMING: All latency measurements are from a single
     machine. Results vary with hardware, OS scheduling, and load.

  5. NO LLM EVALUATION: Contradiction detection and confidence scoring
     use heuristic pattern matching, not LLM judgment. False positive/
     negative rates may differ with an LLM-based evaluator.

  6. SYNTHETIC CONVERSATIONS: Generated conversations are simpler and
     more structured than real human-AI interactions. Real conversations
     have more ambiguity, topic switching, and implicit references.

  7. sqlite-vec AVAILABILITY: Vector search performance depends on
     whether sqlite-vec is installed. Without it, search falls back to
     keyword-only matching.
